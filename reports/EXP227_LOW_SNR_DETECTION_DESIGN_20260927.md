`detect_cells` uses 3D max-pool local maxima and `sigmoid(logit) > threshold`. Normal inference uses probability **0.96875**, a 3 µm pool and D4-averaged logits. Training's detector matching instead uses **logit > 0.3** (probability about 0.574), a 5 µm pool. The existing adaptive inference branch uses probability **0.075** and a 6 µm pool; it decides from the **first two-frame window** and then persists for the movie. It can also re-encode gamma-adjusted images and change ILP edge/disappearance settings and minimum track length. Switching that mode for a low-SNR pocket would confound multiple mechanisms and can create many false detections. Current postprocessing already fills one-frame gaps with raw-intensity-refined synthetic nodes: **1,698** across the eight source movies, while short-track filtering removed **6,149** nodes. Final graphs contain about 243,172 predicted nodes for 2,080 edge-bearing annotated nodes. The 115 missed GT nodes in the source report may therefore originate in peak selection, position error, assignment, or filtering; the prior edge-FN attribution alone does not identify the stage.

## One bounded intervention to test later

**Temporally supported secondary peak for a still-open one-frame gap.** Keep the chosen checkpoint, normal/adaptive decision, image normalization, D4 pass, high-threshold detections, ILP and all current postprocessing parameters unchanged. Cache a secondary set of local maxima from the *same normal logits* at the already used training criterion `logit > 0.3`, with its 5 µm pool. This cache is used only when the movie stays in normal mode; adaptive movies are unchanged because they already use a lower threshold. No extra model forward pass or GT-derived SNR cutoff is needed.

After the existing motion and single-frame gap repair, admit a secondary peak only between a still-open track end at `t−1` and start at `t+1`, each already supported by an adjacent edge. Require the peak at `t` to be within the existing 7 µm tight-motion gate of **both** endpoints, more than the existing 3.2 µm reuse radius from a retained node, and one-to-one with the endpoint pair. Pick deterministically by total physical distance, then logit and coordinates. Add at most `min(25, ceil(0.001 × baseline final nodes))` peaks per movie, inserting one node and two consecutive edges per accepted gap before short-component filtering; keep degree, bounds and graph validation. This is a single frozen mechanism, with no threshold or radius sweep. It extends the current gap repair only where that repair left a gap. The low-contrast result predicts enrichment among recovered nodes, but raw local SNR is **evaluation stratification only**, not a runtime rule learned from source GT.

## Decision and promotion gates

1. First observe epoch20's paired official source8 result and repeat the endpoint-node/SNR attribution on that checkpoint if it is the selected source baseline. Do not select a candidate from epoch10's post hoc pattern alone. If the chosen baseline's missing nodes are mainly present before filtering, or there are too few still-open supported gaps, reject this detection mechanism at the diagnostic stage.
2. If still applicable, create one fresh immutable source8 **no-label** graph stage. Its receipt should count normal/adaptive movies, secondary peaks, eligible gaps, admitted nodes, cap hits and graph changes per movie. Keep telemetry inside per-movie receipts or outside the graph `output/` directory: the existing source10 scorer gate requires exactly eight CSV/JSON pairs plus `status.json` and pins its original plan/checkpoint/code hashes. A new scorer gate must pin the new stage and unchanged official evaluator; it cannot silently reuse the epoch10 gate. Require exact eight source IDs, clean exit, lease release, graph/hash/schema/bounds checks and source-only audit before any source-label score.
3. Compare intervention and control on the **same selected checkpoint and eight movies**. A source-only promotion signal requires at least ten fewer endpoint-limited edge FNs, more newly matched than newly lost GT nodes, counted edge FP increase no greater than the recovered edge TP count, no division-Jaccard loss, and official score gain at least **+0.005** with nonnegative paired score differences in at least six of eight movies. Report per-movie results and node-count penalty. Passing this gate would justify further honest holdout testing; it would not establish target OOF or a 0.9 score.

False positives remain the main risk: a weak local maximum can join two unrelated tracks, add two counted FP edges, raise the node-count penalty, or preserve a false short component. The two-sided support, one-to-one matching and per-movie cap bound this risk but do not prove precision. Existing synthetic gap repair may already cover the recoverable subset, leaving no benefit.
