## Hypothesis and boundary

The public full-frame DeepCenter UNet, refit separately on each source embryo and selected only on disjoint source-inner movies, can supply an embryo-held-out center-veto component for a later *assembled* x138 evaluation. This experiment tests that component's training and source-inner signal. It cannot establish assembled-x138 OOF because the primary, secondary and V1284 learned components and the graph policy need their own common outer-fold provenance and frozen integration.

## Fixed training and selection

Exactly two complete epochs per fold; seed 2026; batch size 8; pool factor 4; base channels 24; AdamW LR 0.001, zero weight decay; public positive-unlabelled weighted BCE and default normalization/augmentation; `frames_per_movie=0`, `movie_limit=None`, `num_workers=2`, `drop_last=False`. Use the pinned trainer with `--split-json` and `--fold-index` set to the fold, `--train-key train --val-key test`, `--epochs 2 --seed 2026 --batch-size 8 --num-workers 2 --val-batches 1000000 --gate-eval-frames 1000000 --gate-thresholds 0.10,0.25 --gate-peak-min-distance 1 --gate-match-radius-um 7.0 --progress-interval 25`. One million exceeds every possible validation batch/frame count in this catalog; the independent verifier must confirm the actual full frame and batch counts from Zarr metadata. Do not use `--resume`, `--overwrite`, `--movie-limit`, `--frames-per-movie`, or any checkpoint initialization.

The unmodified trainer chooses `best.pt` using minimum source-inner validation BCE after each epoch; exact ties keep the earlier epoch because it updates only on strict improvement. The validation loader is ordered and covers every inner frame; it does not drop the last batch. Its `evaluate()` averages *batch* losses, including the final partial batch, as written. Record both epoch rows, selected epoch, config/split/checkpoint SHA256s and bytes, and source-inner gate summary. No threshold or epoch may be chosen using outer-label results. The 0.10/0.25 gate thresholds are fixed diagnostics, not a post-hoc sweep.

## Technical, quality and stop gates

Technical PASS requires exact split and source view, no target ID/path or external checkpoint access, zero denied accesses, two finite epoch rows, every fit and inner frame/batch accounted for per epoch, finite/loadable `best.pt` and `checkpoint_last.pt` with expected epoch/config, best-epoch identity matching the strict minimum-inner-loss rule, clean exit before timeout, no surviving run process/GPU PID, and a RELEASED resource lease. Any violation stops the fold and preserves its receipt. Do not retry under the same identity.

Source-inner **quality gate** for considering separate outer inference: selected validation BCE `<=0.06`; at fixed heatmap threshold `0.25`, sparse-label recall `>=0.20` and predicted peaks per frame in `[1,250]`; all gate fields finite and `evaluated_frames` equal the complete inner-frame count. These are conservative center-signal sanity checks, not graph score or complete-cell precision. If either fold fails, stop the DeepCenter refit path before outer inference; do not tune thresholds or add epochs using that result. A pass only permits separately locked inference and paired organizer scoring after every active x138 learned component is refit on the same source-only folds.

## Resource and queue bound

EXP180's 12-movie run took about 0.7 RTX6000 minutes per epoch with only 24 validation batches and 200 post-training gate frames; it is not a full-source runtime measurement. Fold 0 has roughly 6,386 frames across 71 source movies, and fold 1 roughly 12,800 across 128, so expect about 10–30 minutes and 20–60 minutes respectively including full gate diagnostics; measure actual metadata before reservation. Use one A100, 8 CPU, 32 GiB RAM, at most 4 GiB disk growth and no second Biohub lease. Provisional child caps: fold 0 90 minutes, fold 1 150 minutes; lease minutes 100 and 160 respectively. If a cap proves insufficient, record failure and preregister a new attempt rather than silently extending. Before each reservation, check the common fair queue and physical GPU state; defer if another project waits, another Biohub lease is active, or no A100 is physically idle. Do not preempt or auto-requeue. The active 50-epoch secondary fold-0 job takes priority until it exits and releases its lease.
