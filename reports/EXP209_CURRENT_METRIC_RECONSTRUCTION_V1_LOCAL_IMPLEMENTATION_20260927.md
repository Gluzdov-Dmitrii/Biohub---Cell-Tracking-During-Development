## Gate order and label boundary

1. Stage creates one new immutable code directory only, after checking every
   bundle file and the explicit reviewed manifest SHA. It cannot overwrite an
   existing code directory. Launch similarly checks the staged files and
   explicit reviewed SHA, then creates a unique run directory and durable
   one-shot intent. Ambiguous remote side effects require manual audit.
2. The CPU supervisor hides CUDA and gives each worker a 16 GiB address-space
   cap and 3600-second timeout. Before a graph worker starts, the preflight
   checks the exact 175 historical IDs/partitions and source embryo splits,
   rehashes all 175 raw NPZs, all 59 reverse gap NPZs and all 175 image Zarr
   trees. The preflight opens no GEFF labels. Each worker rechecks its images
   and caches, applies the frozen original functions, compares label-free
   filter/centroid telemetry and historical predicted-node counts, then emits
   canonical graph CSVs and per-graph SHA receipts. A worker error stops the
   sequence without advancing to labels.
3. The supervisor records each worker's exit code, timeout and actual PID/start
   identity, verifies it is gone, and writes a RELEASED receipt. After all
   eight chunks, the independent staged verifier checks 175 graph hashes,
   finite image-bounded coordinates, directed consecutive-frame edges,
   parent/branch limits, exact output file sets, preflight image linkage and
   all exit/release receipts. Only then does it atomically write
   `no_metric_gate.json`. Neither the verifier nor this bundle opens GEFF or
   computes a metric. Historical 175-row replay under the old evaluator must
   be a separate later gate before a current-organizer metric run; it is not
   included or authorized here.

The historical source-selection/reciprocal evidence is development-adapted.
Any eventual score must be labelled a new reconstruction-based,
leakage-controlled reciprocal evaluation. Even a perfect historical metric
replay cannot recover the missing original final-graph SHA evidence.
