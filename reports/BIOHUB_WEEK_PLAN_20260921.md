## Гейты и автоматическое продолжение

Source training/validation не должны содержать heldout embryo. Validation не аугментируется случайно. Исходный EXP214 immutable; все новые выводы отдельно. Пилот сравнивать с matched control, не с историческим числом другой длины обучения. Не считать улучшение source detector доказательством улучшения tracking.

EXP221 сохраняет исходный proxy выбора checkpoint `source_accuracy * source_node_recall`; это **не официальный graph score**. Последующее source graph/robustness оценивание должно быть отдельным явным гейтом перед дорогим расширением. Передача EXP221 и удалённые вычисления явно разрешены последующим ответом пользователя21сентября; первоначальный staging-блок устранён. Обучение обеих веток завершено доepoch24, дальнейшие эпохи не разрешены этим пилотом. Source graph gate использует только две выбранные source-правилом модели (control13/domain23), неизменные8source-validation movies и фиксированные secondary/center с подтверждённым исключением этих8из обучения.

Продвижение: полные prediction receipts, graph/schema/hash gates, официальный full175 paired score >0.7427291486, отсутствие существенного per-embryo провала; отдельно смотреть FP, node recall, divisions. Conditional movie bootstrap не выдавать за независимую embryo uncertainty. Практический сигнал +0.005 полезен для приоритета, но не универсальная статистическая значимость. Две неудачи одного механизма — пересмотр, а не sweep.

Grok анализирует; кластерными командами управляет основной агент. Уведомления только о значимом изменении/ошибке/необходимом действии.
