# Horaz: ограниченный поиск параметров графа, 2026-09-29

Пользователь разрешил запустить эксперименты с ограничением времени. Один GPU, один запуск; 10 000 секунд внутреннего бюджета и жёсткий timeout 10 800 секунд. Новых весов не обучаем. Параметры и группы фиксируются в `work/horaz-bounded-search-20260929/bundle/plan.json` до вычислений.

Гипотеза: баланс learned вероятности связи, расстояния и штрафа деления может улучшить Horaz. Фиксированные 12 вариантов включают baseline; изменяются только четыре множителя assignment config, включая normal/adaptive edge threshold. Детектор и postprocess исходного checkpoint сохраняются. Кандидатные рёбра вычисляются один раз на фильм при минимальном пороге всех вариантов и сохраняются. Оптимизатор по эпохам/seed/LR не запускается.

Подбор на 8 source44 inner-фильмах с исходной source44 E10 моделью. Победитель фиксируется до отдельной проверки на 11 source6 inner-фильмах с source6 E10 моделью. Если обе стадии проходят, единственная проверка на 16 заранее выбранных по SHA256 ID reciprocal-фильмах (8 на эмбрион), не пересекающихся с первыми группами; каждый фильм получает модель другого эмбриона. Эти данные исторически использовались в разработке; результат не называется новым untouched OOF. All199 E10/E20 не оцениваются на их собственном train для выбора параметров.

Выбор: максимум pooled current-organizer score, при равенстве более ранний вариант (baseline первый). Минимальный выигрыш tune +0.005; подтверждение >=0; reciprocal pooled +0.003 и ни один эмбрион не хуже более чем на 0.002. При провале не берём второго победителя и не расширяем поиск. Все необходимые фильмы должны завершиться. Первая временная проба может прекратить поиск, если прогноз не помещается; timeout/ошибка/неполный результат запрещают продвижение.

Если проверка успешна, переносим фиксированные множители на выбранный по правилу пользователя all199 checkpoint (E20 при public >=0.920, иначе E10). До отдельного POST обязательны чистый динамический Kaggle inference Internet off, CSV/graph audit и одна независимая проверка. Целевое время POST до 12:00–13:00 UTC, крайний экспериментальный рубеж 18:00 UTC; учёт оставшегося времени и дневной квоты свежий. Успех поиска и успевание скоринга не гарантированы.

В этом prereg нет разрешения на frozen CSV replay: финальный кандидат обязан заново предсказывать runtime test images. Исторические графы используются только для локального контроля baseline. x138 LOEO/V1284 не возобновляются.
